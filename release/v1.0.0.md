# 奶龙 v1.0.0

奶龙 Codex 桌面宠物的首个公开稳定版本。

## 包含内容

- 奶龙 v2 宠物清单与 `1536 × 2288` WebP 动画图集
- Windows PowerShell 安装脚本
- macOS / Linux Shell 安装脚本
- 安装说明、内部文件校验值和权利说明

## 下载

普通用户请下载：

- `milk-dragon-codex-pet-v1.0.0.zip`
- `milk-dragon-codex-pet-v1.0.0.zip.sha256`（可选，用于核对 ZIP 完整性）

GitHub 自动生成的 Source code 压缩包是完整仓库源码；上面的自定义 ZIP 是更精简的安装包。

## 验证

- 发布前，仓库安装流程已在 Windows、macOS 和 Ubuntu 上重新测试通过。
- 发布后，GitHub Actions 会在三套系统中直接下载 Release ZIP、校验 SHA-256、解压并完成安装测试。

本版本仅面向支持本地自定义 Pets 的 ChatGPT/Codex 桌面应用，不用于网页版 `1536 × 1872` 自定义宠物上传入口。
