# 奶龙 v1.0.1

更新奶龙 v2 图集、安装器修复与质量检查的维护版本。安装包版本 v1.0.1 不改变精灵图格式版本 v2；本地宠物 ID 仍为 `milk-dragon`。

## 下载与安装

- [milk-dragon-codex-pet-v1.0.1.zip](https://github.com/FBBer/codex-milk-dragon-pet/releases/download/v1.0.1/milk-dragon-codex-pet-v1.0.1.zip)：精简本地安装包
- [milk-dragon-codex-pet-v1.0.1.zip.sha256](https://github.com/FBBer/codex-milk-dragon-pet/releases/download/v1.0.1/milk-dragon-codex-pet-v1.0.1.zip.sha256)：整个 ZIP 的 SHA-256 校验文件

解压后进入 `milk-dragon-codex-pet-v1.0.1` 文件夹。Windows 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1`；macOS / Linux 运行 `sh scripts/install.sh`。已有同名宠物时分别添加 `-Force` 或 `--force`。完整步骤见 [安装说明](https://github.com/FBBer/codex-milk-dragon-pet/blob/v1.0.1/release/INSTALL.md)。

GitHub 自动生成的 Source code 压缩包是完整仓库源码；上述自定义 ZIP 是精简安装包。包内包含宠物清单、图集、双平台安装脚本、安装说明、权利说明、`BUILD-INFO.json` 和内部 `SHA256SUMS`。

## 本次变更

- 使用修复后的 `1536 × 2288` 透明无损 WebP v2 图集，73 个必需帧完整、15 个未使用格透明。
- 统一约 0.93 的缩放与基线排布，为跳跃保留头部空间；跳跃位移为 0、6、12、6、0 px，峰值离地 12 px，落地基线误差 0 px。
- 四个主方向通过三份独立盲测；质量门禁保留已复核的 6 条中间方向语义提示和 3 条连续性提示，不宣称零警告。
- 修复 Unix 安装器临时文件名冲突时的清理问题，补充未使用格、跳跃与冲突处理回归测试。
- 加强两平台安装器的路径、链接与临时文件保护；Windows 临时文件使用不覆盖写入并仅清理本次创建的文件。
- 加强版本号验证与打包失败清理，拒绝输出冲突；补充可复现构建、失败回滚和 Windows 独立安装回归测试。
- 方向证据检查拒绝空壳通过报告、缺失主方向、矛盾结果和旧图集哈希；上游校验器的来源与许可边界单独记录。
- 将最终图集文件哈希绑定到方向复核与质量证据，配置 macOS、Linux、Windows 仓库验证及实际 Release 附件安装检查。
- 统一安装文档的版本、目录名与下载入口，明确本地安装和云端 Pets 的边界。

## 验证与使用边界

[仓库公开 QA 报告](https://github.com/FBBer/codex-milk-dragon-pet/blob/v1.0.1/qa/validation-summary.json) 记录图集结构与质量门禁通过，并保留中间方向提示。发布后的三平台附件下载、校验与安装验证结果，请查看 [Validate release 工作流](https://github.com/FBBer/codex-milk-dragon-pet/actions/workflows/validate-release.yml)；工作流配置本身不等同于本版本已通过验证。图片与安装测试不代替具体电脑上悬浮窗口的实时画面确认。

本地图集对应此前已经同步并回读核对的云端版本，但本次 GitHub 发布不会重新上传宠物，也不会修改账号的云端记录。本地 ID `milk-dragon` 与账号生成的云端 ID 不能互换；更新云端时使用支持 v2 的 Pets 工具更新同一条已有记录，并比较回读后的 RGBA 像素。

普通网页上传入口要求 `1536 × 1872`，不能直接使用本包的 `1536 × 2288` v2 图集。Linux 脚本仅安装资源文件，不提供桌面应用或悬浮窗口。
